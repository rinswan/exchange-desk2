Setup steps and script
  1. Sign in to the Google account that should own the sheet and open the Google Sheet.
  2. Extensions > Apps Script. Delete the sample code, paste the script below, and change the secret key in its first line.
  3. Deploy > New deployment > Web app. Execute as: Me. Who has access: Anyone. Deploy and allow the permissions.
  4. Copy the Web app URL (ends with /exec) and paste it above with the same secret key. Press Save settings, then Test connection.
